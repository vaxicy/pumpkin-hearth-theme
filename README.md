A warm autumn desk for VS Code: **cream paper**, **coffee ink**, **pumpkin orange** and a **thread of wood brown**. The light variant feels like a kitchen table at noon, the dark one like the same table by the fireplace — both cut from one palette, so switching changes the light, not the mood.

把一张秋天的书桌搬进 VS Code：**奶油纸面**、**咖啡色字迹**、**南瓜橙**，再配一缕**木头棕**。浅色像正午的厨房餐桌，深色像壁炉边的同一张桌子——两套共用一套色板，切换时变的是光线，不是气氛。

## Contrast / 对比度

Every text color is checked against the surface it actually sits on — editor text, side bar, title bar, status bar, tabs, lists, buttons, badges, links, Git decorations, the 16 ANSI colors and all syntax tokens.

所有文字色都按它实际所落的底色算过一遍对比度：编辑器、侧边栏、标题栏、状态栏、标签页、列表、按钮、角标、链接、Git 装饰色、16 色终端与全部语法 token。

- Body and editor text: **≥ 7:1**
- Syntax colors and UI labels: **≥ 4.5:1**
- Comments and inactive labels: **≥ 3.5:1**
- Cursor, line numbers and decorative marks: **≥ 3:1** where they must be seen

Run `python3 scripts/check-contrast.py` to see the full table.

## Features / 功能

- **Two coordinated variants** — `Pumpkin Hearth Theme Light` and `Pumpkin Hearth Theme Dark` in one extension.
- **One warm palette** — cream paper, pumpkin and burnt orange, coffee ink and wood brown; the dark variant keeps the same hue family on espresso.
- **Readable syntax colors** — olive strings, rust keywords, wood numbers and plum types, each tuned against its own background.
- **Semantic highlighting** enabled, so language-aware tokens are colored beyond the classic TextMate scopes.
- **Full terminal palette** — background, foreground and all 16 ANSI colors taken from the same palette.
- **Complete workbench coverage** — activity bar, side bar, tabs, panels, widgets, inputs, lists, diff editor, Git decorations and 144 UI colors per variant.

- **明暗两套协调变体**——同一个扩展内含 `Pumpkin Hearth Theme Light` 与 `Pumpkin Hearth Theme Dark`。
- **一套暖色板**——奶油纸面、南瓜橙与深赭橙、咖啡字迹、木头棕；深色版把同一组色相放到浓缩咖啡底上。
- **可读的语法配色**——橄榄绿字符串、赭红关键字、木头棕数字、藕紫类型，逐一按各自底色调过。
- **启用语义高亮**，在传统 TextMate scope 之外为语言感知的 token 着色。
- **完整终端配色**——背景、前景和 16 色 ANSI 全部取自同一套色板。
- **工作台全覆盖**——活动栏、侧边栏、标签页、面板、浮窗、输入框、列表、差异编辑器、Git 装饰色，每套 144 个 UI 颜色。

## Installation / 安装

Requires VS Code 1.80 or newer.

1. Search for **Pumpkin Hearth Theme** in the Extensions view (`Ctrl+Shift+X` / `Cmd+Shift+X`), or open the [Marketplace page](https://marketplace.visualstudio.com/items?itemName=lilinhuang.pumpkin-hearth-theme).
2. Or install from a VSIX: download `pumpkin-hearth-theme-1.0.0.vsix`, open the Command Palette (`Ctrl+Shift+P` / `Cmd+Shift+P`) and run **Extensions: Install from VSIX...**.

需要 VS Code 1.80 或更高版本。

1. 在扩展面板（`Ctrl+Shift+X` / `Cmd+Shift+X`）搜索 **Pumpkin Hearth Theme**，或打开 [Marketplace 页面](https://marketplace.visualstudio.com/items?itemName=lilinhuang.pumpkin-hearth-theme)。
2. 也可以从 VSIX 安装：下载 `pumpkin-hearth-theme-1.0.0.vsix`，打开命令面板（`Ctrl+Shift+P` / `Cmd+Shift+P`），运行 **Extensions: Install from VSIX...** 并选择该文件。

Or from the command line:

或使用命令行：

```
ext install lilinhuang.pumpkin-hearth-theme
```

## Activation / 启用

Open the Command Palette (`Ctrl+Shift+P` / `Cmd+Shift+P`), run **Preferences: Color Theme**, and choose **Pumpkin Hearth Theme Light** or **Pumpkin Hearth Theme Dark**. `Ctrl+K Ctrl+T` switches between the two variants at any time.

打开命令面板（`Ctrl+Shift+P` / `Cmd+Shift+P`），运行 **Preferences: Color Theme**，选择 **Pumpkin Hearth Theme Light** 或 **Pumpkin Hearth Theme Dark**。随时可用 `Ctrl+K Ctrl+T` 在两套变体之间切换。

## Development / 开发

Open this folder in VS Code and press `F5` to launch an Extension Development Host with the theme loaded.

在 VS Code 中打开本文件夹并按 `F5`，在扩展开发宿主里预览主题。

Regenerate the real-window screenshots:

重新生成真实窗口截图：

```bash
python3 scripts/capture-real-screenshots.py
```

The script builds a throwaway VS Code profile, installs this theme into it, opens the sample project under `scripts/demo-project` and captures both variants into `store-assets/screenshots/en/`. It checks the captured title bar against `titleBar.activeBackground` and grabs the window again if it was caught inactive.

脚本会临时建一个独立的 VS Code 配置目录，装好本主题，打开 `scripts/demo-project` 示例工程，把两套变体的窗口截图输出到 `store-assets/screenshots/en/`；抓图后会比对标题栏与 `titleBar.activeBackground`，如果窗口不是激活态就重新抓。

Check contrast and refresh `COLOR-SPEC.md`:

检查对比度并刷新 `COLOR-SPEC.md`：

```bash
python3 scripts/check-contrast.py
python3 scripts/validate.py
```

`check-contrast.py` computes WCAG contrast for every text/surface pair and lists anything below its threshold. `validate.py` rebuilds `COLOR-SPEC.md` from the theme JSON files, verifies every color value is a valid hex code, checks the screenshot edges against `titleBar.activeBackground`, and — when a `.vsix` is present — verifies the manifest publisher, version and theme entries.

`check-contrast.py` 会算出每组文字/底色的 WCAG 对比度，低于阈值的直接列出来。`validate.py` 依据主题 JSON 重建 `COLOR-SPEC.md`，校验所有颜色都是合法十六进制，检查截图边缘与 `titleBar.activeBackground` 一致，并在存在 `.vsix` 时校验清单里的发布者、版本与主题条目。

Package the extension:

打包扩展：

```bash
vsce package
```

On Windows, use `py -3` instead of `python3` if `python3` is not on PATH.

Windows 上如果 PATH 里没有 `python3`，把命令换成 `py -3`。
